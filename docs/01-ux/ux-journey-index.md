PMS has **25 user journeys** (21 user-facing, 4 backend jobs) across **17 screens**. Every screen sits inside one shell app (ADR-001).

## Journeys

### Shell (common)

| Journey Id | Journey name | Actor | Trigger | Screens (in order) | Outcome |
| --- | --- | --- | --- | --- | --- |
| UJ-SH-01 | Log in | All roles | Opens PMS | SCR-SH-01 → SCR-SH-03 | Signed in, lands on dashboard |
| UJ-SH-02 | Set password on first login | All roles | Temporary password used | SCR-SH-01 → SCR-SH-02 → SCR-SH-03 | Own password set |
| UJ-SH-03 | See my tasks and status at a glance | All roles | After login / Home | SCR-SH-03 | Knows what needs action |
| UJ-SH-04 | Work through pending approvals | Manager, Admin | Pending count on dashboard | SCR-SH-04 → module review screen | All pending items decided |
| UJ-SH-05 | Log out | All roles | User menu | Any → SCR-SH-01 | Session ended |

| Journey Id | Journey name | Actor | Trigger | Outcome | Visible to users as |
